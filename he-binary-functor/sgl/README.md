# sgl

**Spherical Geometry Language** — Haskell implementation of spherical geometry for braid algebra.

## Files

| File | Language | Description |
|------|----------|-------------|
| `SGL.hs` | Haskell | Core SGL implementation |

## Purpose

SGL provides spherical geometric primitives for:
- Braid group representations on S²
- Fibonacci anyon fusion rules
- Metatron cube projections

## Build

```bash
ghc SGL.hs
```
